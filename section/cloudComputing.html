Definition

Cloud Computing provides computing resources over the Internet instead of using physical servers.

Cloud Resources

  • Servers: Run applications.
  • Storage: Store files.
  • Databases: Manage data.
  • Networking: Connect devices.
  • Computing Power: Process data.

Five Essential Characteristics

  1. On-demand Self-service
  2. Broad Network Access
  3. Resource Pooling
  4. Rapid Elasticity
  5. Measured Service

According to NIST SP 800-145, these characteristics define Cloud Computing.
